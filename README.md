- **백본 비교** · EfficientNet-B0, ResNet50, MobileNetV2의 소재 다중 라벨 분류 성능 비교

- **실험·평가** · ECA·CBAM·CoordAtt·Triplet Attention과 삽입 위치 비교, 분류 성능·파라미터 수·CPU 추론 시간 평가
